# 七维 Topdown 新旧用例对照记录

使用七个互不重复的层级前沿指标，计算完整累计分布的余弦相似度与欧氏距离。这是工具累计输出的描述性比较，不是所有 PMU 事件完整有效的声明。

## 结果：Topdown 相似性：用余弦与欧氏距离比较瓶颈分布

**本节比较 CPU 的瓶颈分配是否接近，函数与操作是否覆盖仍按 7.3 判断。** 采用七维、不重复计权的分区：同为后端受限，还要区分更偏执行资源还是缓存／内存数据供应。余弦看整体分布形状，欧氏距离看各项占比的数值差异，两者并列展示。

**表 7-6：七维指标及其读法。** 向量固定为 `[Retiring, Branch Mispredicts, Machine Clears, Fetch Latency, Fetch Bandwidth, Core Bound, Memory Bound]`。七项合计约 100%；父项 Bad Speculation、Frontend、Backend 已被下面子项替换，不再重复加入向量。

| 指标组 | 实际进入比较的指标 | 看什么 |
|---|---|---|
| 有效工作 | Retiring（有效完成） | 正常完成指令的流水线份额 |
| 无效执行 | Branch Mispredicts（分支误判）＋Machine Clears（流水线清空） | 误推测的具体构成 |
| 指令供应 | Fetch Latency＋Fetch Bandwidth（前端延迟／带宽受限） | 前端供应问题偏延迟还是吞吐 |
| 执行与数据供应 | Core Bound＋Memory Bound（核心执行／存储受限） | 后端更偏执行资源还是缓存／内存供数 |

**怎么算：** 对旧例向量 A、新例向量 B，同时计算以下两项。所有输入均按百分数记为 0–100，不混入不同单位，不额外标准化。IPC 单独列相对变化，idle 不加入距离。

| 指标 | 公式（i 遍历七项） | 读法 |
|---|---|---|
| 七维余弦相似度 | `cos(A,B) = Σ(AᵢBᵢ) / [√ΣAᵢ² × √ΣBᵢ²]` | 越接近 1，整体分布形状越接近 |
| 七维欧氏距离 | `d(A,B) = √Σ(Aᵢ−Bᵢ)²` | 越小，各项占比差异越小；坐标单位为百分点（pp） |

**简单例子：** A=`[20,4,1,15,5,45,10]`，B=`[20,4,1,10,5,50,10]`；前端延迟减少 5 pp、Core 增加 5 pp。余弦为 **0.9933**，欧氏距离为 **√(5²＋5²)=7.07**。余弦仍很高，但数值分配已有变化，因此不单凭“超过 0.99”判定相似；欧氏距离也不是可以直接换算成相似百分比的数值。

**用什么参照：** 旧 OPM／TLC 各五次独立采集，先逐项求均值，再与新例比较。两例均值的余弦为 **0.9962**，欧氏距离为 **4.77**。正文按欧氏距离选择较近的旧例，并展示对同一旧例的余弦与 IPC 变化；完整记录保留两路对照。距离不超过 4.77，称为“旧两场景差异尺度内／相对接近”；超过称为“超出旧尺度”。这是一条本批实验的参照线，不是通用相似性阈值或统计显著性判据。

**本节结论：哪些接近，哪些存在差异？**

1. **大档中相对接近的是 013-v1000、026-u10。** 对各自较近旧例，余弦分别为 0.9976／0.9980，欧氏距离为 3.91／3.85，均在旧例之间的 4.77 尺度内。原始任务中的 009、026，以及小档 021-g5、026-u5、029-u5 也在这一尺度内。
2. **其余大档均超出旧尺度，不能统一称为与旧例相似。** 欧氏距离最大的三项是 031-u20（20.60）、003-u500（18.65）、037-u20（17.30）；具体差异见表 7-8。即使部分余弦仍超过 0.99，也需要结合距离与分项变化判断。
3. **函数覆盖提高，不保证 Topdown 更接近。** 例如 014-n10000 的旧函数覆盖约 91.82%，对较近旧例的欧氏距离仍为 13.71；013-v1000 虽较接近，其构建脚本占比增加的原因仍按 7.3 单独解释。共同函数可以承担不同权重，不能由其中一个指标代替另一个结论。
4. **旧例可以代表共同基础计算，不能替代所有新增任务的 CPU 瓶颈分布。** 按操作选补例仍采用 7.3 的方案；本节用余弦、欧氏距离和分项变化说明补入任务的 CPU 行为差异。

统计取 DevKit 最终 Report-ALL：旧两例为五次独立采集的逐项均值，新配置每种模式一次采集；CPU 0–7 包络未按 PID 裁剪，可能包含同核宿主活动；部分时间点未计数和经验公式复算差异均保留。旧例各次采集到自身均值的最大欧氏距离为 OPM 1.89／TLC 0.55，本批新配置均超出相应旧例的自身范围；“相对接近”不表示重复运行意义上的等价。深层十维暂不作为判据，不把未计数值填零。
